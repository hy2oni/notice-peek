# notice-peek

영남대학교 컴퓨터공학과와 SW중심대학사업단의 새 공지를 모아 보는 개인용 Windows 앱입니다.
계정·서버·클라우드 동기화 없이 공지와 읽음·즐겨찾기를 로컬에 저장합니다.

현재 **5단계 라이트 모드 UI 구현 완료** 상태입니다. 공지 목록, 출처/안 읽음/즐겨찾기 필터,
원문 열기, 읽음·즐겨찾기 변경, 자동 수집과 수동 새로고침을 사용할 수 있습니다.
EXE 폴더 배포와 바탕화면 바로가기는 다음 패키징 단계에서 제공합니다.

## 현재 확정된 동작

- Python 3.11 이상, Tkinter, SQLite. 앱의 외부 패키지 의존성은 없습니다.
- 출처별 최초 수집: 일반 공지 최근 30건 + 고정 공지. 중복은 합치고 **모두 읽음**으로 저장합니다.
- 최초 등록은 신규 알림에 포함하지 않습니다. 최초 수집 완료 여부는 출처별로 관리합니다.
- 이후 수집: 최신 목록부터 확인해 새 게시글 ID만 추가하고 **안 읽음**으로 저장합니다.
- 일반 공지가 기존 기록과 겹치는 페이지까지 확인합니다. 고정 공지만 겹쳐서는 중단하지 않습니다.
- 공지 수정은 추적하지 않습니다. 기존 제목·날짜·URL·읽음·즐겨찾기를 수집 결과로 덮어쓰지 않습니다.
- 본문·이미지·첨부파일을 다운로드하거나 비교하지 않습니다.
- 읽음/안 읽음과 즐겨찾기는 직접 변경하며 즉시 저장합니다.
- UI: 라이트 모드, 가독성 우선, 실행 시 한 번 자동 수집 + 수동 새로고침.
- 신규 표시는 이번 실행에서 발견한 공지에 붙으며 읽음 상태와 독립적입니다.
  같은 실행의 새로고침 후에도 유지하고 앱을 다시 열면 해제합니다.
- 주기적 수집, 트레이 상주, 시작 프로그램 등록은 없습니다.
- 배포는 프로그램 폴더 + 바탕화면 바로가기 방식으로 진행합니다.

초기 `기획서.docx`, `기능명세서.docx`, `프롬포트.md`는 최초 제안의 원본입니다.
이후 사용자와 확정한 위 정책이 우선합니다. 특히 수정 감지 삭제, 최초 읽음 처리,
수동 새로고침 추가, private GitHub 저장소 사용은 초기 문서에서 변경된 사항입니다.

## 앱 실행과 사용법

프로젝트 폴더에서 Windows PowerShell을 열고 실행합니다. Python 3.11 이상만 필요하며
`pip install`은 필요 없습니다. Windows용 Python의 Tkinter 구성 요소가 설치되어 있어야 합니다.

```powershell
python -m notice_peek
```

콘솔 창 없이 개발 버전을 실행하려면 다음 명령을 사용합니다.

```powershell
pythonw run_notice_peek.pyw
```

`.pyw` 파일이 Python과 연결되어 있다면 `run_notice_peek.pyw`를 더블클릭해도 됩니다.
Python 설치 없이 실행되는 EXE와 바탕화면 바로가기는 아직 제공하지 않습니다.

- 시작하면 저장된 목록을 먼저 표시한 뒤 한 번 수집합니다.
- **새로고침** 또는 **F5**로 다시 확인합니다. 수집 중에는 중복 실행을 막습니다.
- **제목 클릭**, 선택 후 **원문 열기** 또는 **Enter**로 기본 브라우저를 엽니다.
  원문을 열어도 읽음 상태는 바뀌지 않습니다.
- **읽음 상태 칸**, 하단 **읽음/안 읽음으로 표시** 또는 목록에서 **Space**로 읽음 상태를 바꿉니다.
- **별 칸** 또는 하단 **즐겨찾기 추가/해제**로 즐겨찾기를 바꿉니다.
- 출처·안 읽음·즐겨찾기 필터를 함께 적용할 수 있습니다. 필터는 네트워크 요청을 하지 않습니다.
- 긴 제목은 해당 행을 선택하면 하단에 전체 표시합니다.
- 창을 닫으면 작업을 취소하고 종료합니다. 네트워크 응답 대기 중이면 마무리 안내가 잠시 표시됩니다.

## 개발용 진단 명령

```powershell
python -m unittest discover -s tests -v
python -m notice_peek sync
python -m notice_peek list
```

`sync`는 한 번 수집하고 종료합니다. `list`는 저장된 공지만 보여주며 네트워크 요청을 하지 않습니다.
이는 개발 검증용 명령이며, 최종 사용자 실행 방식은 바탕화면 아이콘 더블클릭입니다.

개인 데이터와 분리해 시험하려면 DB 경로를 지정할 수 있습니다.

```powershell
python -m notice_peek --database .local\trial.sqlite3
python -m notice_peek sync --database .local\trial.sqlite3
python -m notice_peek list --database .local\trial.sqlite3
```

## 저장 위치와 보존

기본 DB: `%LOCALAPPDATA%\notice-peek\notices.sqlite3`

설치 폴더와 분리되어 있으며 프로그램 업데이트나 재수집 시 초기화하지 않습니다.
앱을 종료한 상태에서 DB를 복사해 백업할 수 있습니다. 읽음·즐겨찾기 변경은 즉시 커밋하고,
공지 추가와 출처별 성공 상태는 하나의 트랜잭션으로 저장합니다.
저장 실패, 손상, 지원하지 않는 DB 버전은 오류로 알리고 파일을 자동 삭제/교체하지 않습니다.
스키마 버전은 SQLite `user_version`으로 관리합니다(현재 1).

## 수집 및 실패 처리

- 수집 대상: [컴퓨터공학과](https://www.yu.ac.kr/cse/community/notice.do),
  [SW중심대학사업단](https://www.yu.ac.kr/swedu/notice/notice.do).
- 공개 HTML 목록만 요청합니다. 식별 키는 `(출처 ID, articleNo)`입니다.
- 순차 요청, 요청 간 최소 0.5초 대기, 네트워크 작업 timeout 10초를 적용합니다.
- 연결 오류와 일부 5xx 응답은 최대 한 번 재시도합니다. 403/429는 재시도하지 않습니다.
- 목록 구조 변경, 비정상적인 빈 목록, 일부 행 누락, 반복 페이지는 분석 오류로 처리합니다.
- 출처별로 필요한 목록을 모두 읽은 뒤 저장합니다. 중간 실패 시 부분 수집을 반영하지 않습니다.
- 한 출처 실패는 다른 출처 수집을 막지 않습니다. 마지막 성공 시각과 기존 공지는 보존합니다.
- 취소 신호는 요청 사이와 저장 직전에 확인합니다. 진행 중인 네트워크 요청은 반환/timeout까지
  기다릴 수 있습니다. 창은 종료 안내를 표시하며 작업 스레드가 끝난 뒤 닫힙니다.
- `SyncService`는 중복 수집을 거부합니다. UI는 별도 작업 스레드에서 호출하고 큐로 결과를 받습니다.
  Tk 위젯은 메인 스레드에서만 조작합니다. 대기 중에도 목록·필터·읽음·즐겨찾기를 사용할 수 있습니다.

## 알려진 범위와 한계

- 최초 최근 30건 이전의 일반 공지를 전체 보관하는 앱이 아닙니다.
- 기존 글 수정·삭제, 이미지/첨부 교체, 미실행 중 생성됐다가 삭제된 공지는 추적하지 않습니다.
- 사이트의 최신 일반 공지 순서를 따릅니다. 과거 글이 새로 고정되면 처음 본 ID로 추가될 수 있습니다.
- 일반 공지와 겹치는 페이지 전체를 처리하므로 경계에서 소수의 과거 공지가 추가될 수 있습니다.
- 기존 일반 공지가 모두 삭제되어 겹치는 기록이 없으면 마지막 페이지까지 확인하며,
  전에 보지 못한 과거 공지도 새 기록으로 들어올 수 있습니다.
- 페이지 이동 중 사이트 목록이 바뀌면 다음 새로고침에서 추가 확인이 필요할 수 있습니다.
- EXE 패키징 및 바로가기 생성은 아직 완료하지 않았습니다.

## 검증

```powershell
python -m unittest discover -s tests -v
```

모의 응답으로 최초 등록·신규·중복 고정 공지·장기간 미실행·출처 일부 실패·취소·저장 실패·
수집 중 사용자 상태 변경·손상 DB 보존을 검증합니다.
`tests/fixtures`는 실제 목록 응답에서 제목/번호/날짜/페이지 이동 영역만 남긴 표본이며,
미리 작성한 신규·실패 시나리오와 구분합니다.

실제 사이트 검증 결과는 [검증 기록](docs/verification.md)에 기록합니다.

## 패키징 계획

다음 단계에서 PyInstaller의 폴더 배포(`--onedir`)와 콘솔 숨김(`--windowed`)을 사용합니다.
Python을 묶어 별도 Python 설치 없이 실행되게 하고 바탕화면 바로가기를 제공합니다.
아직 실행 파일이나 빌드 스크립트는 없으며, 검증된 빌드 명령은 해당 단계에서 추가합니다.

## Git 관리

GitHub `hy2oni/notice-peek`은 private 저장소입니다. 소스, 테스트, 문서만 관리합니다.
개인 DB, 캐시, 로그, 가상환경, 빌드 산출물, `.env`는 `.gitignore`에서 제외합니다.
