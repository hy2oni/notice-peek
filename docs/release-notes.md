# notice-peek 0.1.0

영남대학교 공지를 원하는 게시판별로 모아 보는 개인 제작 Windows 앱입니다.

## 설치

첨부된 **notice-peek-setup.exe**를 다운로드하고 실행하세요.
설치 후 바탕화면의 **notice-peek** 아이콘으로 열면 됩니다.
Windows 10/11 x64용이며 Python과 관리자 권한이 필요하지 않습니다.

## 주요 기능

- 기관명·게시판명 검색과 분류 목록에서 받을 공지를 선택합니다.
- 카탈로그 272개에 사용 가능·미지원·미확인 상태를 표시하고 추가 전 검사합니다.
- 첫 수집은 일반 공지 20건과 고정 공지를 모두 읽음으로 저장합니다.
- 이후 신규 공지는 안 읽음으로 저장하고 이번 실행 동안 제목 앞에 NEW를 붙입니다.
- 제목 더블클릭으로 원문을 열고 읽음 처리하며, 즐겨찾기와 필터를 제공합니다.
- 출처 제거는 확인 후 해당 출처의 공지 기록을 함께 삭제합니다.
- 공지 수정은 추적하지 않습니다. 읽음·즐겨찾기와 공지 기록은 PC에만 저장합니다.

업데이트·제거 시 공지 DB는 보존됩니다. 설치 파일에는 다른 사용자의 공지 기록이 없습니다.
학교 공식 앱이 아닙니다. 사이트 구조 변경에 따라 일부 게시판의 수집이 중단될 수 있습니다.
서명 인증서는 적용하지 않았습니다. SHA256SUMS.txt로 첨부 파일 해시를 확인할 수 있습니다.
