# 출처 선택 화면 — 4단계

첫 실행과 이후 변경에 같은 라이트 모드 선택창을 사용한다. 메인 화면의 **출처 설정** 버튼으로 다시 열 수 있다.

## 선택

- 검색창: 기관·게시판·분류 이름으로 검색한다. 여러 검색어는 모두 포함된 항목을 찾는다.
- 분류 드롭다운: 클릭해서 분류를 고른다.
- 체크박스: 사용 가능한 게시판을 원하는 개수만 선택한다. 검색·분류를 바꿔도 체크 상태를 유지한다. 키보드 Space도 사용할 수 있다.
- **선택한 출처만**: 여러 항목을 고른 뒤 최종 선택을 모아 볼 수 있다.
- 기관명과 게시판명을 나란히 보여준다. 선택한 행의 상세 영역에는 전체 이름·지원 안내·URL을 표시한다.
- **사용 가능 / 미지원 / 확인 필요** 상태를 표시한다. 미지원·확인 필요는 새로 체크할 수 없다.

기본 선택은 비어 있다. 아무것도 선택하지 않고 저장할 수 있고, 이후 실행에서 첫 선택창을 반복해서 띄우지 않는다. 취소하면 저장하지 않는다. 기존 사용자에게는 이관된 구독을 유지하며 첫 선택창 대신 메인 목록을 표시한다.

예술대학의 실기·음악경연대회와 경영학과 대학원처럼 페이지 제목이 동일한 항목 3개는 공식 메뉴·경로에 맞춰 게시판 표시명을 구분했다. ID와 URL은 유지했다.

## 검사와 저장

추가할 게시판은 백그라운드에서 실제 목록을 읽어 검사한다. 일반 글 최근 20건과 고정 글을 확인하며, 상세 페이지·본문·첨부파일은 요청하지 않는다. 검사한 목록을 최초 수집 결과로 함께 저장하여 같은 페이지를 다시 요청하지 않는다. 최초 글은 모두 읽음이며 NEW로 표시하지 않는다.

추가한 항목 중 하나라도 검사에 실패하면 모든 변경을 보류한다. 실패한 행을 표시하고 구체적인 이유를 보여주며, 기존 구독·공지·플래그는 유지한다. 실패 항목을 해제하거나 재시도할 수 있다. 검사 취소나 창 닫기도 저장하지 않는다.

제거할 항목이 있으면 저장 직전에 출처 목록과 **공지·읽음·즐겨찾기 기록이 모두 삭제됨**을 한 번 안내한다. 확인창의 기본값은 아니오다. 취소하면 기존 기록을 유지한다. 전체 선택과 최초 공지 저장은 한 트랜잭션으로 적용한다. 설정창을 연 뒤 다른 작업에서 구독을 변경했다면 덮어쓰지 않고 다시 열도록 안내한다.

검사 중에는 선택 변경과 중복 저장을 막는다. 설정창과 일반 새로고침도 동시에 실행하지 않는다. 취소·앱 종료 시 현재 요청의 제한 시간 안에서 작업을 마무리한다.

## 메인 화면

출처 필터·수집 상태·원문 주소 검사에 실제 구독 목록을 사용한다. 여러 출처의 상태 영역은 제한된 높이 안에서 스크롤한다. 새로 선택한 기존 출처는 포함된 로고를 읽고, 로고가 없는 출처는 이름으로 표시한다. 긴 출처명은 목록 칸에서 줄이고 상세 영역에서는 전체 이름을 보여준다.

구독 0개는 **출처 설정에서 받을 공지를 선택해 주세요**라는 안내를 표시하고 네트워크 요청을 하지 않는다. 창 크기는 화면 높이를 고려해 하단 동작 버튼이 화면 밖으로 밀리지 않게 설정한다.

## 검증

선택·검색·분류·지원 상태, 무구독 시작과 재실행, 추가 출처의 동적 표시와 원문 열기, 최초 목록 재사용, 일부 검사 실패 시 보존, 제거 확인 취소·확인, 검사 중 취소와 종료, 다수 출처 상태 영역, 저장 트랜잭션 롤백을 테스트했다.

자동화 테스트는 기존 수집·읽음·원문 동작을 포함해 총 60개를 통과했다.

실제 공개 홈페이지의 컴퓨터공학전공·SW중심대학사업단·통계학과를 별도 DB에 등록했다. 각각 25건·23건·26건, 합계 74건이 일반 글 20건 및 고정 글로 저장됐고 모두 읽음이었다. 실제 Tk 창의 선택 화면과 등록 후 목록을 캡처해 라이트 모드 배치와 로고·출처명 표시를 확인했다.

개인 DB와 기존 배포 EXE는 변경하지 않았다. 이 단계는 개발 소스에 반영되었으며 새 EXE 빌드·배포는 후속 단계에서 진행한다. 다음 5단계에서 소식 열을 제거하고 제목 앞에 작은 NEW 표시를 넣는다.
