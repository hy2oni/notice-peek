## 실제 게시판 검증

사용자의 실사용 DB와 분리한 임시 DB에서 실행했습니다. 최초 실행 후 같은 DB로 다시 수집했고,
검증이 끝난 임시 DB는 정리했습니다. 상세·첨부·이미지는 요청하지 않았습니다.

| 실행 | 학과 | 사업단 | 전체 소요 시간 |
|---|---|---|---|
| 최초 | 3페이지, 34건 등록 | 3페이지, 32건 등록 | 13.99초 |
| 다시 수집 | 1페이지, 신규 0건 | 1페이지, 신규 0건 | 5.82초 |

총 66건이며 모두 읽음이고, 재수집 뒤에도 총 66건을 유지했습니다.
각 최초 건수는 일반 공지 30건 + 학과 고정 4건 / 사업단 고정 2건입니다.
이는 해당 시점·환경의 실측값이며 매번 같은 속도를 보장하지 않습니다.

## 6단계 Windows 패키징 검증

검증일: 2026-10-02 (한국 시간).

- Python 3.11.9의 프로젝트 전용 `.venv`, PyInstaller 6.22.3으로 빌드했습니다.
- 빌드 스크립트에서 자동 테스트 **34개가 통과**했습니다.
- `dist/notice-peek/notice-peek.exe`와 `_internal`을 생성했습니다.
- PE Machine `0x8664`(x64), Subsystem `2`(Windows GUI)를 확인했습니다. 콘솔용 빌드가 아닙니다.
- 전체 배포 폴더는 **28.13 MiB**, 986개 파일입니다. 파일 대부분은 Python/Tcl/Tk 런타임 리소스입니다.
- EXE를 프로젝트 밖 임시 작업 폴더에서 실행했습니다. 자식 프로세스의 PATH는 Windows System32만
  남기고 PYTHONHOME/PYTHONPATH도 제거했습니다. 따라서 PATH의 Python 실행 파일에 의존하지 않았습니다.
- 실사용 경로에 시험 데이터를 남기지 않도록 자식 프로세스의 LOCALAPPDATA만 임시 폴더로 지정했습니다.
- 실제 EXE 창은 약 **2.05초** 만에 나타났고, 두 게시판의 최초 **66건** 수집은 약 **16.14초**였습니다.
- 읽음·즐겨찾기 값을 저장한 뒤 종료·재실행했고, 기존 66건과 사용자 상태가 유지됐습니다.
- 재실행 중 수집이 진행되는 시점에 창 닫기 메시지를 전달했습니다. 실행부터 종료까지 약
  **2.77초**였으며 종료 코드 0, 데이터 보존을 확인했습니다.
- 세 번째 실행에서 정상 재수집 후 중복 없이 66건을 유지하고 종료 코드 0으로 종료했습니다.
- EXE 창을 캡처해 라이트 모드 화면, 한글, 앱 아이콘과 Tk 리소스가 정상 표시되는 것을 확인했습니다.
- 바탕화면 `notice-peek.lnk`를 생성하고 대상 EXE, 작업 폴더, 아이콘 경로와 파일 존재를 검증했습니다.
- 검증 종료 후 실행 중인 `notice-peek` 프로세스가 없음을 확인했습니다.

별도로 Python을 제거한 다른 PC에서의 실행은 확인하지 않았습니다. 현재 PC에서 Python을 PATH에서
제외한 실행 및 번들된 런타임으로의 동작을 확인한 결과입니다. EXE와 개인 DB는 Git에 포함하지 않습니다.

- 전체 테스트는 등록 검사 실패 시 변경 취소, 삭제 확인 취소, 수집 중 종료,
  출처 0개 저장, NEW 표시와 재실행 초기화, 더블클릭 및 로고 배치도 포함한다.
- 개발 EXE를 프로젝트 밖 임시 작업 폴더와 임시 LOCALAPPDATA에서 실행했다.
  PATH에는 System32만 남기고 PYTHONHOME/PYTHONPATH를 제거했다.
- 새 설치의 실제 설정창에서 선택 0개, 게시판 272개 및 지원 상태 표시를 확인했다.
  취소·종료 후 DB에 구독이 생성되지 않았다.
- 개인 DB는 읽기 전용으로 복사했다. EXE가 복사본을 버전 1에서 2로 이관하며
  백업 1개를 생성했고, 기존 공지 70건의 모든 필드가 보존됐다.
  컴퓨터공학전공·SW중심대학사업단 모두 새 수집 시각과 success 상태를 확인했다.
  실제 목록에서 소식 열 제거 및 출처 로고를 확인하고 종료 코드 0으로 종료했다.
- 빌드 폴더: `dist/develop/notice-peek`, 993개 파일, 총 29,784,717바이트.
  EXE SHA256: `49897d8afe29264b2b239466b6df99c0fa75d5f953f4d94fb2a67c23c64efcec`.

패키징된 EXE는 GUI 전용이므로 진단용 CLI 인수를 사용하지 않는다.
CLI 검사는 `python -m notice_peek`로 실행한다. 초기 검증 스크립트가 EXE를
CLI로 호출해 대기 시간 초과가 발생했으며, GUI 진입점에 맞게 수정 후 재검증했다.
별도 Python 미설치 PC에서의 실행과 설치 프로그램은 아직 검증하지 않았다.
실사용 DB, 기존 배포 EXE, 바탕화면 바로가기는 변경하지 않았다.
검증 스크립트·결과·EXE는 Git에서 제외한다. 다음은 7단계 설치·배포 준비다.

## 출처 확장 7단계: 설치 파일·배포 준비

2026-10-11: Inno Setup 6.7.3으로 `dist/release/notice-peek-setup.exe` 제작.
6단계에서 검증한 개발 EXE를 `package.ps1 -SkipBuild`로 포장했다.
앱 코드는 변경하지 않았으며 이 단계에서 앱 자동 테스트를 다시 실행하지 않았다.

- 관리자 권한 없는 사용자별 설치, 한국어 라이트 설치 화면, Windows 10/11 x64 대상.
- 기본 설치 위치는 `%LOCALAPPDATA%\Programs\notice-peek`이며 바탕화면·시작 메뉴 바로가기를 자동 생성한다.
- 같은 설치 스크립트의 테스트용 경로로 설치·업데이트·제거를 실제 실행했다.
  페이로드 993개 파일의 SHA256이 빌드 원본과 동일했고,
  두 바로가기의 실행 파일과 작업 폴더도 일치했다.
- 설치된 앱을 별도 LOCALAPPDATA와 Python을 제외한 PATH에서 실행해 라이트 화면·로고·기존 기록 표시를 확인했다.
  제한된 네트워크에서 연결 실패 안내와 저장된 안 읽음·즐겨찾기 공지 보존을 확인하고 정상 종료 코드 0을 확인했다.
- 재설치 전후 DB SHA256이 동일했다. 제거 후 프로그램과 두 바로가기는 사라지고 DB는 그대로 남았다.
- Python 라이선스·구성요소 고지를 포함해 최종 재포장한 뒤 설치·파일 비교·바로가기·재설치·제거 검사를 다시 통과했다.
- 최종 설치 파일 크기: 11,167,133바이트 (약 10.65 MiB).
  SHA256: `56f19af763cc687452c518fbe445013ea4555038d0e80b06465b1870c95ebeb7`.
- README 최상단에 고정 이름 설치 파일 다운로드 링크를 준비했다.
  현재 저장소 private·릴리스 없음이므로 공개·업로드 전에는 다운로드되지 않는다고 명시했다.

테스트 설치는 실사용 바탕화면·시작 메뉴·앱 제거 등록을 변경하지 않는 경로를 사용했다.
개인 DB와 기존 폴더 배포본·바로가기는 유지했다. 별도 PC의 실제 설치와 서명 인증서는 미검증·미적용이다.
저장소 공개와 첫 릴리스 업로드는 다음 8단계 커밋·푸시와 함께 진행한다.
